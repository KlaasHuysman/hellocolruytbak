# Maaltijdplanner – HelloColruytBak (versie 2)

Statische website die de prompt voor de persoonlijke maaltijdplanner overzichtelijk toont, met knoppen om de volledige prompt te kopiëren of als `.txt` te downloaden.

- `index.html` – de website (één bestand, geen afhankelijkheden)
- `prompt.txt` – de ruwe prompttekst

## Publiceren met GitHub Pages
Settings → Pages → *Deploy from a branch* → branch `main`, map `/ (root)`.
